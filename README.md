**MACRO PAD**

The files contains a schematic and PCB building of the MacroPad.
The Schematic drawing portrays:
  - 1 Arduino Microcontroller
  - 3 Switches
The Arduino is connected to the 3 switches along side external GND power which allows the functionality of a basic key.
Each press is recorded which allows user to create 3 different MACROS.
Alongside the Schematic and PCB display, there is a CAD design attached, made from FUSION 360. It allows 3 keys to be slotted inside with dimensions perfect to fit in the Arduino and the switches.
